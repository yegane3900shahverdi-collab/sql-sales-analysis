# SQL Sales Analysis Project

## Overview
This project analyzes sales data using SQL Server and T-SQL to explore business performance, customer purchasing behavior, and product revenue.

The analysis is performed using the **TSQLV4 sample database**.

## Business Objectives
- Explore and understand the sales dataset.
- Calculate key sales performance metrics.
- Analyze yearly revenue trends and growth.
- Identify top customers by revenue.
- Analyze customer purchasing activity.
- Identify top-performing products.

## Tools & Technologies
- SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)

## Key Metrics
| Metric | Value |
|---|---:|
| Total Orders | 830 |
| Unique Customers | 89 |
| Total Revenue | 1,265,793.04 |
| Average Order Value (AOV) | 1,525.05 |

## Key Findings
- Revenue increased by **196.57%** from 2014 to 2015.
- Revenue decreased by **28.60%** in 2016 compared with 2015.
- Customer revenue rankings were analyzed to identify high-value customers.
- Product revenue analysis identified top-performing products.

## SQL Skills Demonstrated
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- JOINs
- DISTINCT
- Common Table Expressions (CTEs)
- Window Functions (LAG)
- Revenue calculations
- KPI analysis
